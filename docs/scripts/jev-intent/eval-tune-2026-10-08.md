# Intent eval — first run on the tuning split (2026-10-08)

The first `mix intent.eval --split tune` run, **before any tuning**, against the
labelled fixture in ex-tales-forge (PR: the eval set + `mix intent.eval`). It
scores three readers on the same 247 tuning-split items: the proposed **Jev**
one-call read, today's **heuristic**, and today's **Tier 1 LLM** intent call.

> ⚠️ **Draft labels** (`reviewed: false`). These numbers are only as good as the
> labels, which Case and Fredrik have not reviewed yet. No thresholds were
> tuned. Read this as a direction, not a verdict.

## Headline

- **Jev safety is already perfect on this set:** recall **1.00** (42/42 attacks
  flagged), precision **1.00**, **0** false positives on 205 benign items, and
  **0** injection quote-leaks. Per attack class: jailbreak 14/14, prompt
  injection 17/17, nefarious 11/11 (exact-class 0.93 / 1.00 / 1.00). The
  heuristic and the Tier 1 call (today's intent prompt has no safety field)
  flag nothing.
- **Jev action accuracy already meets target** at **93.1%** (≥ 90%), vs the
  heuristic's 62.8% and Tier 1's 70.4%. Material (consequence-class) error is
  **2.4%** (≤ 3%).
- **Cost:** Jev **$0.030** for the whole split (~$0.00012/item); Tier 1
  **$0.515** (2 items errored); heuristic free.

## What the misses mean

- **Target / move-target, skill-check-vs-none, deferred / this-turn-vs-later**
  are exactly the fields tuning is for: candidate-list wording, the question
  text, label descriptions and how much context goes in. A share of the "misses"
  is likely **draft-label noise** — the deferred/"this turn vs later" labels in
  particular are the hardest to call (plan-for-later vs act-now), and are first
  in line for Case's review.
- **ECE 0.19 overstates the problem.** The reliability table is monotonic and
  Jev is actually slightly **under-confident** at the low end (the 0.2–0.3 bin is
  80% correct, the 0.3–0.4 bin 69%), so a simple monotonic recalibration of the
  reported confidence would pull ECE down without changing a single decision.
- **Tier 1 safety recall is 0** only because today's default intent prompt has
  no safety field; this is the baseline as it stands, not a regression.
