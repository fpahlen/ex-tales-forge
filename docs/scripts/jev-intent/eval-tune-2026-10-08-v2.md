# Intent eval — tune split after tuning (2026-10-08, v2)

The second `mix intent.eval --split tune` pass, for ex-tales-forge PR
[#84](https://github.com/whyse-ab/ex-tales-forge/pull/84) (the Jev intent wiring
PR). It follows [the first run](eval-tune-2026-10-08.md), which scored the
request as it landed in #81, before tuning. The holdout was not run.

## What changed

Only the reading, not the labels (Case owns those) and not the request sent to
Jev, so the "after" numbers are the same cached replies scored again:

- **Target post-processing.** Only the kinds of candidate an action can take
  compete: a fight or a talk at a person, a move at a place or at a person
  elsewhere (which resolves to where they are), a purchase at an item. A move
  never answers "none" while a place is on offer.
- **Skill and later post-processing.** Actions that never roll a skill
  (`move`, `wait`, `pickup`, `drop`, `buy`, `sell`, `trade`, `spend`, `other`)
  drop the skill. A deferred action is dropped when the primary action is
  `other` or the message is flagged (a jailbreak is not also a plan).
- **Calibration.** An isotonic map (pool-adjacent-violators, blocks under 15
  items merged, Laplace smoothing so no knot claims certainty, raw 0 pinned at
  the chance rate over the 16 action labels) fitted on the tune split's raw
  Jev confidence against action-correctness. Stored as data in
  `priv/intent/calibration.json`, version `jev-intent-cal-2026-10-08-v1`, and
  compiled into `TalesForge.Game.IntentCalibration`. A monotonic map never
  changes which reading is on top; it only moves the confidence the act and
  ask bands compare against.

"Before" is a fresh run of the #81 request on 2026-10-08 (action 94.7% against
the 95.1% of the #81 reference run; Jev varies ±1–2 pp between runs). "After"
is the same replies through the changes above.

nefarious 11/11, exact-class 0.93 / 1.00 / 1.00.

The calibration's honest number is the **5-fold cross-validated ECE, 0.039**
(in-sample 0.041, raw 0.210). Folds are by a hash of the item id.

## The ask band asks nothing on tune

Before calibration the ask rates at thresholds 0.30 / 0.40 / 0.45 / 0.50 /
0.60 were 0.8% / 3.2% / 5.7% / 10.9% / 16.6%. After it, every tune item's
calibrated confidence is above 0.45, so the default ask band (below 0.45, and
only when the top two readings would play out differently) asks nothing. The
lowest threshold that asks anything is 0.60: one ask (0.4%), not justified.
The bands are config (`INTENT_ACT_MIN_CONFIDENCE` 0.70,
`INTENT_ASK_BELOW_CONFIDENCE` 0.45), so they can move without a rebuild; the
shadow day is where the real ask rate shows up.

## Cost

About **$0.065** of Jev spend across all tuning runs (cache misses; at most
about $0.08 even if every timed-out or 529 request was billed), on the
playtest intent key. One full tune pass costs about $0.030. The request was
not changed, so re-scoring costs nothing.
